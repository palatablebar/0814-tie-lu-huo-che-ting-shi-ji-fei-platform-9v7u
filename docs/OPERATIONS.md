# 批次操作

1. 用带异常样例做阶段预览，查看列数、必填值和冲突记录。
2. 执行批次后，在业务阶段定位异常分组并核对原始记录键。
3. 修复来源文件，重新上传并执行。历史批次保留供复核。
4. 对账无差异且无坏行时可签发。对仍有差异的版本可填写暂缓意见。
5. 导出复核证据并保存于交接记录。

单文件 256 KiB，最多 2000 条逻辑记录。容器重启后保留批次。恢复时使用原 Docker Compose 数据卷。

## 月末交接处置

1. 批次对账无差异后签发；有争议先在处置面板登记争议，未结争议期间原凭据完整保留。
2. 对已签发批次设置保留期限（默认 1825 天）并执行处置。未签发、未结争议或保留期未满的批次结论为 `RETAINED`。
3. 保留期满且无争议的批次结论为 `PURGED`：凭据说明列与复核意见被覆盖清空，处置结果不含原文或哈希，无法还原；记录键、金额与业务分组仍可核对，补录记录不删除。
4. 处置任务按依据幂等，重试不新增记录；依据变化（争议、签发版本、保留期）才生成新版本，旧版本保留在版本台账中。
5. 交接写入失败时整事务回滚，旧处置结果与原凭据不受影响。
6. 页面查看与 JSON 下载读取同一份处置结果，下载文件随交接记录归档。
